# Library---Management---System
A simple Library Management System developed in Python. This console-based application allows users to add books and members, borrow and return books, and view books, members, and active loans.

## Features

- Add new books
- Add new members
- Borrow books
- Return books
- View all books
- View all members
- View active loans
- Custom exception handling

## Project Structure

```text
library-management-system/
│── README.md
│── Book.py
│── Exceptions.py
│── Library_services.py

│── Member.py


## File Descriptions

* **Book.py** – Defines the `Book` class.
* **Member.py** – Defines the `Member` class.
* **Loan.py** – Defines the `Loan` class.
* **Exceptions.py** – Contains custom exception classes.
* **Library_services.py** – Handles all library operations.
* **Main.py** – Runs the main menu program.
* **README.md** – Project documentation.

## Requirements

* Python 3.x

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the program using:

"python Main.py"
